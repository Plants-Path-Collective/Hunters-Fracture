Guía de Contribución y Buenas Prácticas

Nomenclatura

Comentarios y documentación en español. Código en inglés, siguiendo las convenciones estándar de C#: PascalCase para métodos/clases, camelCase para variables locales.

Commits

Todos los commits se escriben en inglés, siguiendo un formato basado en Conventional Commits. El mensaje indica el tipo de cambio, el sistema o archivo afectado entre paréntesis, y una descripción breve en imperativo. Al final del mensaje se listan los archivos editados o modificados.

type(scope): description

El scope suele ser el sistema (dialogue, combat, inputs) o un archivo puntual cuando el cambio es muy acotado.

Tipos

TipoUso
featNueva funcionalidad o mecánica.
fixCorrección de un bug.
refactorCambio interno que no altera el comportamiento.
choreMantenimiento: configuración, dependencias, assets menores.
docsCambios en documentación.
styleFormato o nombres, sin cambios de lógica.
perfMejoras de rendimiento.
testPruebas o herramientas de testing.

Estructura del mensaje

  • Línea de asunto: type(scope): description — descripción en minúscula, imperativo, sin punto final.
  • Cuerpo (opcional): detalle adicional del cambio, si el asunto no alcanza para explicarlo.
  • Archivos: lista de archivos editados o modificados, bajo el encabezado Files changed:.

Ejemplos

feat(dialogue): add timeout fallback for unanswered prompts

Files changed:
- Assets/Scripts/02_Dialogue/DialogueManager.cs
- Assets/00_Dialogue/NPC_Flora_Ch2.asset
fix(combat): prevent negative HP from status ticks

Files changed:
- Assets/Scripts/01_Combat/StatusBuffTracker.cs
chore(inputs): bump Input System package to 1.19.0

Files changed:
- Packages/manifest.json
