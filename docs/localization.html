Sistema de Localización

Unity Localization como capa de datos para todo el texto traducible del juego.

El proyecto utiliza el paquete oficial Unity Localization (com.unity.localization) para diálogos, UI y wiki. La edición de traducciones se realiza desde la ventana nativa del paquete (Window > Asset Management > Localization Tables), o desde la Google Spreadsheet "Hunters: Fracture of Time - Localization".

  • Locales: definidos en Edit > Project Settings > Localization.
  • String Tables: organizadas por dominio funcional, en vez de una única tabla global, para evitar cargar en memoria contenido que el jugador no está usando (ej. la wiki completa al iniciar el juego).
  • Convención de keys: prefijo por dominio + identificador descriptivo, ej. npc_flora_line_003, menu_pause_resume, wiki_bestiary_slime_desc.
  • Integración con Google Sheets: flujo de sincronización opcional sobre las String Tables existentes — no las reemplaza, permite editarlas de forma colaborativa fuera del Editor.
  • Uso en código: cualquier texto traducible se expone como LocalizedString (ver DialogueLine.dialogueText, AnswerOption.answerText y SpeakerSO.speakerName), resuelto en runtime según el Locale activo.

Convención de tablas

Dialogue_<NPC o Capítulo>Diálogos agrupados por NPC principal o por capítulo/zona.
UI_CommonTextos genéricos repetidos en toda la interfaz.
UI_MenusTextos específicos de cada menú.
Wiki_<Categoría>Una tabla por sección grande de la wiki.
Nota

Por ahora la organización por tablas está aplicada al sistema de diálogo. La extensión a menús y wiki sigue el mismo paquete y convención, pero su integración en código aún está pendiente.
