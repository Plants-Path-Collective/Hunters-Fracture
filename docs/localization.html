06 · SISTEMA

Sistema de Localización

Unity Localization organiza las traducciones en locales y String Tables; el código consulta las entradas con LocalizedString y, para voz, LocalizedAudioClip.

Locales configurados

Los locales y códigos configurados en Assets/Localization/Locales/ son:

  • en — English; locale de proyecto y selector de inicio predeterminado.
  • es-CL — Spanish (Chile).
  • ja-JP — Japanese (Japan).
  • zh-Hans — Chinese (Simplified).

GameManager y MainMenuManager esperan a que termine LocalizationSettings.InitializationOperation y después asignan LocalizationSettings.SelectedLocale al cambiar el idioma.

Colecciones de String Tables

Los assets de tablas están bajo Assets/Localization/String Tables/. Las colecciones que aparecen en el proyecto incluyen:

DominioEjemplos de colección
DiálogoDialogues
InterfazUI_Common, UI_Combat, UI_Inputs, UI_Menus
Contenido de juegoUI_Consumables, UI_Units, Units_Elowen, Units_Fasila, Units_Iter, Units_Renjiro
DemoDemos_Combat1

El nombre de la colección puede diferir de la carpeta que contiene sus assets: por ejemplo, la colección UI_Units está bajo UI_Items/. La disponibilidad de traducciones debe comprobarse para cada colección y locale; no todas las colecciones contienen archivos para los cuatro idiomas.

Uso en runtime

Los datos y componentes mantienen referencias a tablas y keys mediante LocalizedString. El sistema de diálogo resuelve texto de líneas, nombres de hablantes y respuestas, además de clips de voz localizados. También hay referencias localizadas para nombres y efectos de consumibles, nombres y descripciones de acciones, etiquetas y datos de unidades y componentes de interfaz. Los componentes de UI que se suscriben a StringChanged actualizan el texto cuando cambia el locale.

Edición y sincronización

Las String Tables y sus entradas son los datos locales del proyecto. Existe un asset de servicio de Google Sheets en Assets/Localization/Google Sheets Service.asset; su presencia por sí sola no confirma que cada colección esté vinculada a una hoja compartida ni que la sincronización externa esté configurada para el equipo. Comprueba el flujo de importación/exportación de Localization Tables antes de usarlo y no guardes secretos de acceso en documentación o repositorios.
