Sistema de Diálogo

Las conversaciones se describen con ScriptableObjects y las reproduce DialogueManager. Los textos y las voces admiten localización; las respuestas pueden continuar el diálogo o ejecutar acciones.

Flujo del sistema

El jugador interactúa dentro del trigger
                │
                ▼
       ConversationTrigger
                │
                ├── usa IConversationOverride si devuelve una conversación
                └── si no, usa conversations[conversationIndex]
                │
                ▼
  DialogueManager cambia el mapa de input y pausa el reloj
                │
                ▼
       Reproduce DialogueLine
                │
       ┌────────┴─────────┐
       ▼                  ▼
 Elige respuesta      Vence el tiempo
       │                  │
 Ejecuta actions     Usa noResponseConversation
       └────────┬─────────┘
                ▼
         Fin de la conversación

Componentes principales

ConversationSO Asset con un arreglo ordenado de líneas de diálogo.
SpeakerSO Datos reutilizables del hablante: nombre localizado y retrato.
DialogueManager Reproduce líneas, muestra respuestas, ejecuta acciones y controla el estado de diálogo.
ConversationTrigger Detecta la interacción del jugador y selecciona una conversación para ese NPC.

Datos de conversación

TipoCampos y comportamiento
DialogueLineHablante opcional, LocalizedString, voz localizada opcional, respuestas, tiempo de respuesta y conversación de fallback.
AnswerOptionTexto localizado, nextConversation y arreglo opcional de DialogueActionSO.
SpeakerSONombre localizado y retrato. Si una línea no define hablante, se mantiene el último mostrado.

Los textos referencian entradas de Unity Localization; los clips de voz también pueden variar por idioma. Consulta Sistema de Localización.

Interacción y selección del NPC

ConversationTrigger requiere un Collider, implementa IPlayerInteractable y comienza la conversación cuando el jugador está dentro del trigger. Su npcID identifica al personaje; conversationIndex selecciona una entrada de conversations y se guarda en PlayerPrefs con una clave por NPC.

Si hay un componente que implemente IConversationOverride, el trigger lo consulta primero. NpcQuestGiver implementa esta interfaz y busca una conversación según el estado de las misiones del NPC. Si no hay una conversación aplicable, se usa el arreglo regular. Un override no avanza el índice regular; este llega hasta el último elemento y no vuelve al inicio.

Con NpcQuestGiver, request se actualiza según las misiones asociadas al NPC: se activa mientras haya alguna Active o ReadyToTurnIn. Sin ese componente, la bandera sigue siendo manual.

El orden de selección de diálogos de misión y la resolución de empates se detallan en Sistema de Misiones.

Reproducción y respuestas

DialogueManager admite los modos TextOnly, VoiceOnly y Both. Para iniciar una conversación necesita un asset con al menos una línea. Al comenzar, cambia al mapa de input Dialogue y solicita una pausa del GameClock; al finalizar, restaura el mapa previo y libera la pausa.

  • Al seleccionar una respuesta, emite onChoiceSelected, ejecuta sus acciones y luego pasa a nextConversation, si existe.
  • Si vence answerTimeout, no se ejecutan acciones y se usa noResponseConversation, si está asignada.
  • Al terminar normalmente, limpia la interfaz, libera el trigger y emite onConversationEnd.
  • StopConversation() interrumpe el diálogo, finaliza el trigger y emite onConversationEnd, pero no reporta el hito de charla. También llama a AdvanceConversation(), por lo que el índice regular puede avanzar si request está desactivado.

Acciones y misiones

DialogueActionSO es la clase base para acciones configuradas en una respuesta. El sistema de misiones incluye AcceptQuestActionSO y TurnInQuestActionSO, que llaman a QuestManager.Accept y QuestManager.TryTurnIn. Las acciones se ejecutan solo cuando el jugador selecciona esa respuesta; el timeout no las ejecuta. El selector NpcQuestGiver prioriza el diálogo de misión por encima de las conversaciones regulares. Consulta Sistema de Misiones.

Eventos

DialogueManager expone eventos Unity para inicio y fin de conversación, línea mostrada y respuesta elegida. Además, al finalizar normalmente una conversación con un trigger, reporta talk:{NPC_ID} mediante ChallengeEvents. Este hito puede avanzar objetivos de misión o condiciones de desafío que escuchen ese ID.

Nota

conversationIndex se guarda en PlayerPrefs por NPC. Las conversaciones provistas por un override no modifican ese índice.
