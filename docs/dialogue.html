04 · SISTEMA

Sistema de Diálogo

Arquitectura data-driven basada en ScriptableObjects para desacoplar los datos de la lógica de reproducción.

Cada conversación se representa mediante un ConversationSO, el cual almacena un conjunto ordenado de DialogueLine. Cada línea puede contener un hablante (SpeakerSO), texto localizado, una línea de voz opcional (AudioClip), hasta cuatro respuestas posibles (AnswerOption), un tiempo límite para responder y una conversación alternativa que se ejecuta cuando el jugador no realiza ninguna elección.

Tanto dialogueText como answerText son de tipo LocalizedString (Unity Localization): no almacenan el texto directamente, sino una referencia a una entrada dentro de una String Table — ver Sistema de Localización.

La reproducción está centralizada en DialogueManager, un sistema global persistente encargado de iniciar y finalizar diálogos, mostrar la interfaz correspondiente (nombre y retrato del hablante), reproducir líneas de voz, gestionar las respuestas del jugador y controlar la transición entre conversaciones mediante Coroutines. Su funcionamiento es independiente de los NPCs: cualquier sistema puede iniciar una conversación con solo una referencia a un ConversationSO.

Cada NPC dispone de un componente ConversationTrigger, responsable de detectar la entrada del jugador mediante un Trigger Collider e iniciar la conversación correspondiente. Además posee un identificador único (NPC_ID) y un índice de progreso (conversationIndex) que registra cuántas veces el jugador ha interactuado con él, permitiendo presentar distintas conversaciones conforme avanza la relación entre el jugador y el personaje.

El ConversationTrigger también incorpora una bandera de estado (request) que bloquea el avance del conversationIndex mientras exista una solicitud o misión pendiente asociada al personaje, manteniendo el mismo diálogo hasta que la condición correspondiente se resuelve.

Flujo del sistema

Jugador entra al Trigger Collider
            │
            ▼
     ConversationTrigger
            │
            ▼
   Obtiene NPC_ID y conversationIndex
            │
            ▼
   Selecciona ConversationSO correspondiente
            │
            ▼
   DialogueManager.StartConversation()
            │
            ▼
       Reproduce DialogueLine
            │
            ├── Texto
            ├── Voz (opcional)
            └── Respuestas (opcional)
            │
            ▼
   ¿Finalizó la conversación?
            │
            ▼
      ¿request == false?
            │
      Sí ───────► conversationIndex++
      No ───────► Mantiene el mismo índice
            │
            ▼
     Guarda el progreso del NPC

Componentes principales

ConversationSO Contenedor de datos que representa una conversación completa.
SpeakerSO Contenedor de datos reutilizable para un personaje (nombre localizado y retrato).
DialogueManager Sistema global encargado de reproducir y controlar el flujo completo de las conversaciones.
ConversationTrigger Gestiona el inicio de la conversación y el progreso individual de cada NPC.
Nota

Actualmente el progreso de las conversaciones se almacena con PlayerPrefs por NPC, combinando NPC_ID + conversationIndex. En futuras iteraciones este sistema será integrado con el gestor de guardado y el sistema de misiones, permitiendo persistencia completa entre partidas y gestión centralizada del estado narrativo.
