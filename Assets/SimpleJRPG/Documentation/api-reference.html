API Reference

Complete reference for every type, member, method, event, and struct in SimpleJRPG.

ICombatant Interface

The interface users implement for their characters and enemies. Battle never modifies combatants directly — it calls TakeDamage() and Heal(), and your implementation decides what that means.

Member Type Description
Name string (get) Display name
IsAlive bool (get) Whether combatant is alive
Team int (get) Team identifier (0 = player)
Speed float (get) Speed stat for turn order
TakeDamage(int amount) void Reduce HP by amount
Heal(int amount) void Restore HP by amount

ITurnSystem Interface

The interface for turn order logic. Implement this to create custom turn systems, or use one of the built-in implementations.

Member Type Description
Init(List<ICombatant> combatants) void Initialize with combatant list
GetNextActor() ICombatant Get next combatant to act
GetTimeline() IReadOnlyList<ICombatant> Predicted turn order
OnActorDied(ICombatant) void Notify of combatant death
OnActorAdded(ICombatant) void Notify of combatant addition
OnTurnEnd() void Notify turn completed

BattleEvents — Structs

DamageEvent

Field Type Description
Source ICombatant Who dealt the damage
Target ICombatant Who received the damage
Amount int Damage amount
DamageType string Pass-through damage type
Element string Pass-through element
WasCrit bool Whether the hit was critical

HealEvent

Field Type Description
Source ICombatant Who performed the heal
Target ICombatant Who was healed

StatusEvent

Field Type Description
Source ICombatant Who applied the status
Target ICombatant Who received the status

BuffEvent

Field Type Description
Source ICombatant Who applied the buff
Target ICombatant Who received the buff

Duration int Duration in turns (-1 = permanent)

KOEvent

Field Type Description

TurnEvent

Field Type Description

GroupDamageEvent

Field Type Description

GroupHealEvent

Field Type Description

GroupStatusEvent

Field Type Description

GroupBuffEvent

Field Type Description
Source ICombatant Who applied the buffs

BattleHistoryEntry

Field Type Description
Sequence int Global sequence number
TurnNumber int Turn when event occurred
EventType string Type of event recorded

BattleResult

Field Type Description

History IReadOnlyList<BattleHistoryEntry> Complete battle event log

BattleEvents — Before-Events (Classes)

Before-events are mutable classes (not structs) that allow subscribers to modify or cancel actions before they execute.

BeforeDamageEvent

Field Type Description
Source ICombatant Who is dealing the damage
Target ICombatant Who will receive the damage
Amount int (settable) Damage amount — modify to change final damage
DamageType string Pass-through damage type
Element string Pass-through element
IsCrit bool Whether the hit is critical
Cancel bool (settable) Set to true to prevent damage entirely

BeforeHealEvent

Field Type Description
Source ICombatant Who is performing the heal
Target ICombatant Who will be healed
Amount int (settable) Heal amount — modify to change final heal
Cancel bool (settable) Set to true to prevent heal entirely

BattleState Enum

Value Description
NotStarted Battle has not begun yet
WaitingForCommands Waiting for the next turn to begin
Executing A turn is in progress
Victory Player team won
Defeat Player team lost
Fled A combatant fled the battle
