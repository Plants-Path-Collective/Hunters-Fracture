Demos

6 interactive demo scenes that showcase every feature of SimpleJRPG.

Overview

SimpleJRPG ships with 6 interactive demo scenes, each generated via a menu item in the Unity editor. Every scene is fully self-contained with its own UI and demonstrates a specific feature of the API. No setup required — just generate and hit Play.

Generating Demos

Open the Unity menu bar and go to Window > Simple JRPG. Each menu item generates a fully-wired scene with combatants, UI, and event subscriptions already configured.

Battle Core Demo

Menu: Window > Simple JRPG > Generate Battle Core Demo

The kitchen-sink demo. Demonstrates ALL core features of the Battle class: full lifecycle (StartBattle through EndBattle), DealDamage (single-target and multi-target), Heal, Kill, Revive, before-events (toggle cancel and toggle halve), ApplyStatus, ApplyBuff, Flee, battle history, RemoveCombatant, BattleResult, and the GetEnemies/GetAllies query helpers.

UI layout: Party HP panel on the left, action buttons in the center, and a scrolling event log on the right.

Classic Turn Demo

Menu: Window > Simple JRPG > Generate Classic Turn Demo

A 3v3 party battle using ClassicTurnSystem. Step through turns one at a time, see the turn order displayed, watch auto-attacks resolve, observe round cycling as all combatants take their turns, and see dead combatants get skipped. Includes revive to demonstrate mid-battle turn order updates.

ATB Turn Demo

Menu: Window > Simple JRPG > Generate ATB Turn Demo

A 3v3 party battle using ATBTurnSystem. A Tick button advances time, filling each combatant's gauge based on their speed. Gauge bars are displayed per combatant. When a combatant's gauge is full, they become ready and you can select an action for them.

Timeline Turn Demo

Menu: Window > Simple JRPG > Generate Timeline Turn Demo

A 3v3 party battle using TimelineTurnSystem. Displays the full timeline showing when each combatant will act next. Actions have different cast-time costs — Quick (50), Normal (100), and Heavy (200) — that push the actor further down the timeline. Tick progression advances the timeline and resolves turns as they come up.

Press Turn Demo

Menu: Window > Simple JRPG > Generate Press Turn Demo

A two-team battle using PressTurnSystem. Displays the current phase and the team's turn point pool as Full and Half points. Demonstrates SelectActor to pick who acts, ConsumeAction for normal actions, ConvertAction to convert a Full point to Half, and ConsumeAllActions to end the phase early.

Action Point Turn Demo

Menu: Window > Simple JRPG > Generate Action Point Turn Demo

A 3v3 party battle using ActionPointTurnSystem. Displays each combatant's current AP (Action Points). Spending AP queues extra actions in a single turn. Saving AP banks points by skipping a turn. Demonstrates the risk/reward of going negative on AP for burst damage versus saving up for future turns.

Scene Location Demo scenes are saved to Assets/SimpleJRPG/Scenes/. You can regenerate them at any time — existing scenes will be overwritten.
