Installation

Get SimpleJRPG into your Unity project in under a minute.

Import from Unity Asset Store

SimpleJRPG is available on the Unity Asset Store. Follow these steps to add it to your project:

  1. Open the Unity Editor and navigate to Window > Package Manager.
  2. In the Package Manager, select My Assets from the dropdown in the top-left.
  3. Search for SimpleJRPG in your asset list.
  4. Click Download if you haven't already, then click Import.
  5. In the Import dialog, ensure all files are selected and click Import.
  6. SimpleJRPG will appear under Assets/SimpleJRPG/ in your project.

Folder Structure

After importing, you'll find the following structure in your project:

Assets/SimpleJRPG/
├── Runtime/          — Core battle API
├── Demo/             — Interactive demo scenes
├── Documentation/    — This documentation
└── Scenes/           — Generated demo scenes

The Runtime/ folder contains everything you need. The other folders are optional and can be safely deleted if you only want the core API.

Assembly Definition

SimpleJRPG ships with an assembly definition file (SimpleJRPG.asmdef) located in the Runtime/ folder. This assembly definition is configured with noEngineReferences: true, which means:

  • Pure C# — No dependency on UnityEngine or any Unity API.
  • Testable — You can reference this assembly from a test project and run unit tests with any .NET test framework, no Unity test runner required.
  • Portable — The code can be compiled and used outside of Unity entirely, making it easy to share logic between a Unity client and a server, for example.

To reference SimpleJRPG from your own assembly definitions, simply add SimpleJRPG to your asmdef's reference list.

Requirements

  • Unity 2021.3+ — Any recent Unity version is supported (2021 LTS or newer).
  • No third-party dependencies — SimpleJRPG does not rely on any external packages or plugins.
Zero Dependencies SimpleJRPG has zero external dependencies. It's pure C# — no MonoBehaviours, no ScriptableObjects, no Unity API calls.
